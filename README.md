# 195 WG Enlisted Development Dashboard

Multi-tenant career development dashboard for the 195th Wing.
Built with Streamlit + Supabase.

---

## Setup (one time)

### 1. Run the database schema in Supabase

1. Go to your Supabase project → **SQL Editor**
2. Paste the contents of `schema.sql` and click **Run**
3. This creates all tables and inserts the 10 tenant units

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Generate fake demo data

```bash
python3 data_generator.py
```

This creates one admin account per tenant and 50 members per tenant.

### 4. Migrate existing 149 IS CSV data (optional)

```bash
python3 migration.py
```

This replaces the generated 149 IS members with your real CSV data.

### 5. Run locally

```bash
streamlit run app.py
```

---

## Deploy to Streamlit Community Cloud

1. Push this repo to GitHub (private repo recommended)
2. Go to **share.streamlit.io**
3. Click **New app** → select your repo → `app.py`
4. Done — your app is live

**Note:** The Supabase credentials are currently hardcoded in `database.py`.
To secure them, move them to Streamlit Secrets:

In `database.py` replace:
```python
SUPABASE_URL = "https://..."
SUPABASE_KEY = "eyJ..."
```

With:
```python
SUPABASE_URL = st.secrets["SUPABASE_URL"]
SUPABASE_KEY = st.secrets["SUPABASE_KEY"]
```

Then in Streamlit Cloud → your app → **Settings → Secrets**, add:
```toml
SUPABASE_URL = "https://hjxxwposxhsreqphfzfa.supabase.co"
SUPABASE_KEY = "your-key-here"
```
